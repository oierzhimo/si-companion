## 必须保留的识别点

1. 浅绿色直刘海和长发，两侧各有一个可分辨的圆形丸子头；正面缩小后仍能看出左右各一个。
2. 两侧丸子头附近的墨色小翅膀或墨迹状饰件，与发髻轮廓分离，不做成普通黑色发夹；上臂另有黑色向上弯曲的护饰，两类结构不能混为一体。
3. 高低不完全对称的深色角，带金色内侧纹理；尖耳、蓝色眼睛、偏冷静而熟悉的表情。
4. 黑金颈饰、白色交叉领片、深蓝灰色胸衣、中央黑色 V 形边和垂下的饰件；肩臂黑色构件上有金色十字形连接件。上臂露出的皮肤、肩部硬质构件与前臂颜料纹样须分层辨认。
5. 白色几何纹前片、蓝色竖向边条、从肩臂构件旁独立垂下的宽大袍片和不对称外袍；保留水墨、浅青玉色与金色链饰的层次。全身比例参考实机截图，避免将其改成通用制服或长裙。
6. 长袜和厚底短靴保持一致，脚底位置可作为动画对齐点；腿侧环形物与尾部的关系待原始侧背图核实，不能直接视为尾端。

- 方法：只对同一张 RGBA 源图做均匀缩放和连续几何变换。先按可见 alpha 边界等比缩放，保留全部服饰、面部、纹身和透明边缘；以约 2 倍画布超采样、预乘 alpha 滤波后降采样，减少灰边和锯齿。左右重心使用随高度平滑增大的剪切，双脚所在底线为不动点；呼吸使用以底线为锚点的轻微竖向缩放。两者均为慢速、闭环信号，混合不同谐波，避免单频机械重复。全程没有眼部或嘴部编辑，也不把它称为骨骼动画。
- 节奏：24 fps 名义，8.00 秒无缝循环，192 帧；APNG 的逐帧时长为 41/42 ms，总和 8000 ms，`loop=0`，透明背景、dispose none、blend source。动作上限约为头部横向 3.2 px、竖向 1.8 px，人物四周保留安全边距；这是可见但克制的微动作，不是完整动作重制。
- 关键帧总览固定展示起点、左重心、右重心和呼吸高点，并标注时间；供无法播放 APNG 时检查。静态总览使用棋盘透明底和脚底线，便于核对透明边缘与脚部锚定。
