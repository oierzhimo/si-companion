# 1.2.1 语音预览

- 在 1.2.0 桌宠上增加可选 VoiceStudio 语音。默认关闭，仅主动互动及专注完成会请求发声；普通定时短句仍只显示文字。
- 仅连接本机 `127.0.0.1:3900`。发声前核对声线 ID；声线不存在、接口中断或生成失败时继续文字互动，不自动换用其他人的声线。
- 合成在后台线程执行，短时间重复请求会去重；音量仅作用于桌宠播放文件，不改系统音量。提供本机已有运行环境的主动启动按钮，退出桌宠时停止由桌宠启动的引擎。
- 本机用“管理员，我在。”完成 24 kHz、单声道、1.36 秒的真实 WAV 生成，非静音解码通过；后端 render trace 为 `outcome: complete`。缓存播放和自启/停止由桌宠侧集成检查通过。声线是否符合角色仍待用户试听判断。
- 本预览仍使用旧动画图集。1.3 的立绘候选和动作重制尚未接入运行版。
- 修复便携版启动时误初始化 HTTPS 证书导致的 `[Errno 2]` 弹窗，并同步修复“连接本机引擎”入口。重新打包后，异地解压运行与本机 VoiceStudio 启动、试听、停止检查均通过。
