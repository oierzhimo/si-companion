# 2.0.0a5 全新电脑加入协同修复

- 全新 Windows 安装首次启用协同时，创建并持久保存空事件账本及独立设备身份，不再把零计数误作旧存档基线。因此可以接收另一台电脑已有的非零旧记录。
- 已有计数或手记的旧存档继续备份并生成稳定迁移基线；两份不同旧存档仍拒绝自动合并。a3/a4 已产生的零值账本不会自动改写，升级前阅读 [局域网协同说明](LAN_SYNC_PREVIEW.md)。
- 新增两独立进程的真实 TLS 回环测试，覆盖配对、双向事件、重复同步和重启后身份及授权保留。同机测试不能代替第二台物理电脑验证。
- 保留 2.0.0a4 的全屏隐藏与可选本机模型对话。形象与动画仍使用旧图集，1.3 造型未定稿；Android 和鸿蒙真机协同未验证。

完整验证边界见 [验证记录](VALIDATION.md) 与发布目录的 `VERIFIED-2.0.0a5.json`。
