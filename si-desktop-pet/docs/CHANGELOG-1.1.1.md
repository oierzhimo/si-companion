# 1.1.1 更新

修复陪伴面板预览人物在 Windows 高缩放比例下偏到左上角并被裁切的问题。

预览现在按人物实际可见轮廓居中，保留标题和底部文字区域。每次启动、切换动作、调整窗口大小及屏幕缩放比例变化后，绘制时都会重新计算位置和合适尺寸，不需要手动调整。

此前错误地用高清图片的物理像素尺寸计算窗口内位置；新版统一使用窗口逻辑坐标与可见轮廓，保留高 DPI 清晰度。坐姿、躺姿、站姿均适配。

## 升级

退出旧版后完整解压 1.1.1，双击 `Si-DesktopPet.exe`。如需保留记录，将旧版 `data` 文件夹复制到新版目录。桌面上自由移动的桌宠位置仍按原有逻辑保存；本次修复针对陪伴面板中的人物展示区。
