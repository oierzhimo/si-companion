## 打包修复

构建环境 PATH 含一个导出符号带版本后缀的 ICU DLL，而 Qt 使用 Windows 自带的无版本后缀 ICU API。首次打包误收集了前者，出现 QtCore 加载错误。最终 spec 明确排除该 ICU、Windows API-set 与 UCRT 系统 DLL，保留 Python 与 Qt 的应用运行库；修正后的实际 EXE 已启动通过。此过滤规则随源码构建配置交付。
