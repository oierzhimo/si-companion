# 2.0.0a1 Windows 手动协同预览

## 使用

1. 完整解压 `SiDesktopPet-2.0.0a1-ManualSyncPreview-Windows-x64.zip` 到新的可写文件夹，保留旧版文件夹。
2. 如需继承旧记录，先退出旧桌宠，再复制旧版 `data/settings.json` 到新版 `data/`。不要把另一台电脑的 `settings.sync-v1.json` 复制过来；每台设备要有自己的身份。
3. 双击 `Start-Sync-Preview.cmd`。首次启用会保留 `settings.pre-sync.json` 备份并创建事件账本。以后也用此入口启动。
4. 在“相伴手记”页导出事件包，传到另一台 Windows PC 导入；另一台也导出事件包，传回本机导入。重复导入不会重复计数。

## 已做

- 摸头、点心、专注完成与手记以独立事件保存；亲密度和次数从事件确定性计算。
- 复制自相同旧存档的迁移基数去重；迁移前已经分叉的旧存档拒绝自动合并，避免重复累计。
- 事件包有摘要，导入前完整校验；同一事件 ID 内容冲突则整体拒绝导入。
- 手动导入后更新面板计数和手记；位置、缩放、置顶、语音等本机设置不被覆盖。
- 如果旧版程序在账本创建后又单独增加旧存档计数，同步入口会停止并提示人工恢复；账本先保存而旧计数未及时写入时，可从账本恢复。

## 验证边界

- Windows 11 x64 本机通过 38 项单元测试、Qt 互动检查，以及异地解压、无 Python PATH 的实际 EXE 启动与账本创建验证。
- 两台 PC 的离线事件交换在隔离目录模拟并核对结果；尚未在两台物理 PC 上执行完整往返。
- 无自动配对或网络传输；事件包摘要用于发现损坏，不是身份认证。管理员须自行保管包含互动与手记的事件包。
- Android 手机与鸿蒙 5 平板客户端未实现；运行时仍使用旧动作图集，1.3 面部与动画尚未完成。
