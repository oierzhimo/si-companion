# 1.2.0 更新记录

- 新增面向管理员的本地互动短句，减少重复与无端打断。
- 降低随机走动、小动作和台词出现频率；非行走动作播放一次后保持稳定姿态。
- 新增安静陪伴和靠边坐好；专注时靠边、降低不透明度并允许鼠标穿透。
- 修复提前结束专注后的停滞、专注期间找回仍穿透、托盘专注菜单文字过期，以及隐藏时气泡重新出现。
- 靠边时保留完整角色轮廓，手动靠边持续到下一次主动操作；散步按钮不再改写自动散步设置。
- 修复窗口可见段变化引起的支撑丢失，缩短窗口边缘跟随周期，并让小工具窗参与遮挡判断。
- 延续 1.1.1 的便携存档格式，旧数据目录可直接复制迁移。
- 保留原有图像素材；新立绘候选尚未进入运行版动作图集。
- VoiceStudio 发声、多 PC 和移动端协同仍在后续版本，见 `ROADMAP.md`。
