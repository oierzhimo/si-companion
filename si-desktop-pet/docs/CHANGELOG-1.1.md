# 1.1.0 更新

- 清晰度：重新从原始生成大图提取全部动作，替代 192×208 小图。运行帧为 1536×1664；按显示器实际缩放比例绘制，避免 Windows 高 DPI 二次放大。三倍大小、4K / 200% 时输出 1152×1248 实际像素。
- 左右散步分别重新制作八帧，包含落脚、经过与摆腿；按实际移动距离推进脚步。起步、停步与转向有加减速过渡。
- 文字气泡改为直接绘制的不透明深色圆角背景，浅色文字与描边；跟随桌宠，限制在当前屏幕内，避免跑出边缘。
- 待机改为随机间隔眨眼，并穿插观察、思考与招手；避免连续重复同一小动作。鼠标视线跟随期间也可眨眼。
- 高清帧使用有上限的缓存，避免所有大图一直驻留内存。

## 升级

1. 从系统托盘退出旧版。
2. 将 1.1.0 ZIP 完整解压到新文件夹。
3. 如需保留记录，把旧版的 `data` 文件夹复制到新版文件夹，替换同名目录。
4. 双击 `Si-DesktopPet.exe`。设置里的大小可调至 3 倍。

保持默认 2 倍，已有大小设置也会保留。本版仍为 Windows 10/11 x64 免安装应用，整文件夹复制即可。

## 画质说明与验证

`qa/v11-4k-comparison.png` 为 3840×2160 的同尺寸新旧对比。三倍大小的物理输出、1/1.5/2/3 倍屏幕缩放、气泡背景不透明、步态与待机调度均有自动检查。

本版恢复原始素材细节，并提供高清画布和正确的高 DPI 输出；没有将插值放大宣称为逐帧原生 4K 重绘。个别原始视线素材的细节少于站姿和新步行，仍受原图限制。应用无需额外高清工具或联网。
