## 下轮出图须核对

- 面部：蓝青虹膜、较小的五官、柔和短下巴，避免继续放大眼睛；表情保持平静和熟悉。
- 发型：双侧小盘髻、细长分叉且不对称的黑金龙角、头侧墨色小翅膀。发色的翠绿与灰薄荷层次须取自原图，避免只按文字提高饱和度。
- 胸口：核对硬质白灰表面、中央开口、方形扣件、领部饰件与钢蓝镶边；已有候选的结构不能自证正确。
- 肩部：不对称黑金护饰与独立编绳，保持窄肩；核对编绳是否曾误画成链条。
- 手臂至手：裸臂上的墨色/青墨颜料延至手背和指尖，没有袖口。新增图鉴描述为淡墨渗色，之前用户角色图呈冷蓝灰前臂与深蓝手部，两者需在模型中核对光照与走向，不能直接凭文字覆盖已有参考。
- 墨翼：头侧小饰件、背部纹样与展开形态分别核对；不以通用羽翼代替水墨笔触。
