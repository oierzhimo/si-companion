# 2.0.0a3 局域网协同预览

解压后，普通陪伴仍可直接双击 Si-DesktopPet.exe。要交换记录，先退出普通实例，再双击 Start-Sync-Preview.cmd，进入“相伴手记 → 局域网配对与同步”。

新增 3 分钟一次性配对邀请、TLS 加密传输、证书指纹核对、每台设备独立授权与撤销，以及可选的每分钟自动连接。网络工作不会在界面线程等待，记录合并与计数刷新只在界面线程写入。重复事件按 ID 去重。

同机两份存档已通过真实 TLS 网络、面板按钮与自动定时同步检查。打包测试发现并修复 TLS 初始化所需证书策略文件遗漏；保留了原运行环境的策略文件。发布验证报告见 release/VERIFIED-2.0.0a3.json。

首次迁移须从同一份旧存档启用账本。已有两份不同累计时会拒绝合并，需要先处理迁移；请阅读 LAN_SYNC_PREVIEW.md。本版本仍使用旧图集；第二台物理 PC、安卓与鸿蒙尚未验收。
