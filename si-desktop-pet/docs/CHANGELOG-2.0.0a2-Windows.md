# 2.0.0a2 Windows 便携版

## 运行与迁移

完整解压 `SiDesktopPet-2.0.0a2-Windows-x64.zip`，双击 `Si-DesktopPet.exe`。第一次会打开陪伴面板。右键桌宠或托盘图标退出；需要找回被遮挡的桌宠时，使用托盘“找回祀”。

继承旧记录：先退出旧版，将旧文件夹的 `data/settings.json` 复制到新版 `data/`，保留旧文件夹。不要直接覆盖旧版程序。语音默认关闭，只有本机 VoiceStudio 可用且用户主动启用时才使用。

需要在 Windows PC 之间手动交换记录时，先退出普通桌宠，再使用 `Start-Sync-Preview.cmd`；首次启用会备份存档。该入口属于预览，操作和边界见 `MANUAL_SYNC_PREVIEW.txt`。默认启动不会创建协同账本。

## 本版变化

- 修正便携目录下 `data/app.log` 无法打开时的启动路径：尝试当前用户数据目录，仍不可写时退回临时目录，避免仅因日志文件路径失效而不能启动。
- 修正陪伴面板显示时，退出操作可能被“关闭面板后留在托盘”的行为拦截的问题；主动退出现在会结束整个桌宠。
- 保留明确话题互动、安静靠边、鼠标穿透与托盘找回、专注计时、默认关闭的本机语音，以及可选 Windows 手动事件交换。
- 提供独立的便携启动说明、完整文件夹和源码包；不覆盖任何早期发布包。

## 当前边界

仍使用旧动作图集。面部、前臂颜料的颜色与纹路、裙装及高质量动作在校准中，尚未接入。两台物理 PC、Android 手机、鸿蒙 5 平板的完整协同尚未验收。Windows 10 尚无本次实机启动记录。
