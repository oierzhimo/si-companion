# 1.2.2 互动预览

## 本次变化

- 新增“和祀说一句”五个明确话题：想做点新东西、有点卡住了、想休息一会儿、想听你聊画、先安静陪我。桌宠只回应用户主动点选的内容，不根据窗口标题、截图、键盘内容或日程推断用户正在做什么。
- “先安静陪我”会靠边坐下、暂停自主散步并降低不透明度；关闭“安静陪伴”会释放这次 `quiet_dock` 靠边停留，不会留下无法解除的停靠状态。使用“找回祀”也会结束这次靠边停留。
- 修正互动过程中的可见性问题：
  - 走到屏幕边缘时按完整精灵画布转身，避免人物或画布被裁掉；
  - 高窗口顶边按当前缩放和实际可见头顶预留空间，避免站在高窗口上时头部出屏；
  - 在屏幕边缘放大显示、从专注或安静状态找回时重新夹取完整画布；
  - 新增显示器接入后也监听其可用区域变化；
  - 鼠标穿透的可见覆盖窗口仍作为遮挡物处理，不能当作可站立平台。
- 新增独立的 1.2.2 打包与校验入口，输出名称包含 `InteractionPreview`，不会写入 1.2.0 或 1.2.1 的稳定包名；稳定包会记录哈希并在打包后复核未变化。
- 便携包内附 `INTERACTION_PREVIEW.txt`，说明互动范围、数据迁移和旧包保护事项。

## 版本边界

- 这是 **1.2.2 互动预览**，不是 1.3 形象或动画完成版。
- 运行时仍读取旧的动作图集。`art-source/v1.3/` 中的 v12 是面部待校准的造型基准，未替换运行版素材；v13 至 v16 因整图重绘造成形象漂移已弃用，1.3 的动画、接缝和缩小尺寸验收尚未完成。
- 语音仍为可选的本机 VoiceStudio 功能，默认关闭；未连接时文字陪伴继续工作。语音不改变本次互动话题的本地预设性质。
- 实际验证环境只有单显示器 1920×1080、系统 200% 缩放；混合 DPI 多屏仍属于未验证范围。

## 安装与存档

1. 先完整解压新的 `SiDesktopPet-1.2.2-InteractionPreview-Windows-x64.zip` 到新文件夹，不要覆盖 1.2.0/1.2.1 文件夹。
2. 退出旧程序，把旧版 `data/` 复制到新文件夹，再启动 `Si-DesktopPet.exe`。
3. 如果只想试互动，可以不迁移存档；测试存档不会被当作新用户的陪伴记录。

## 已知限制

- 1.3 的立绘、表情、动作重制和动画接缝仍未完成，不能把候选立绘当作已完成素材。
- 互动话题是本地原创短句，不是联网 AI，也不声称看到用户的真实工作内容。
- 高窗口顶边、屏幕边缘和缩放后的边界已经做自动检查；特殊系统窗口、独占全屏和混合 DPI 多屏仍需更多实机验证。
