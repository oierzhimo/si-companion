# 2.0.0a6 窗口顶边转身与旧手记保护

- 自动散步到普通窗口顶边时，按当前可站立段提前转身；用原有速度平滑自然减速、反向。太窄的窗口顶边会停下，不再反复翻方向。手动走下边缘、跳跃与拖拽仍按用户操作执行。
- 首次启用局域网同步前，检查旧手记能否原样迁移。内容非空但格式异常时会明确拒绝，保留原设置，不创建半成品账本；合法旧手记和全新空白安装继续按原规则处理。
- 沿用 2.0.0a5 的新电脑空账本加入修复、可选本机对话和全屏隐藏。a3/a4 已生成的零值账本仍不自动改写。
- 1.3 立绘 v18 与站立微动作仍处于待审阶段；本版运行时继续使用旧图集。第二台物理 PC、安卓手机和鸿蒙平板尚未完成真机协同验收。

测试与限制见 [验证记录](VALIDATION.md)、[局域网协同说明](LAN_SYNC_PREVIEW.md)及发布目录的 `VERIFIED-2.0.0a6.json`。
