# Ark-Pets 行为对照

参考版本：2026-10-15 读取的 Ark-Pets `v3.x` README。来源：https://github.com/isHarryh/Ark-Pets 。本表以单角色桌宠的行为为范围。

| Ark-Pets 行为 | 祀独立版实现 |
| --- | --- |
| 行走 | 独立左右步行动画、随机方向、速度设置、屏幕边缘转向 |
| 坐下 | 独立生成的坐姿眨眼循环，可随机触发或右键指定 |
| 躺下 | 独立生成的侧卧呼吸循环，可随机触发或指定休息 |
| 戳一戳 | 单击、招手、风格短句与亲密度变化 |
| 概率特殊动作 | 随机思考 / 灵光一闪，也可右键触发 |
| 自由落体 | 按时间积分的重力、速度上限、扫掠碰撞防穿透、轻微回弹 |
| 拖拽到扩展屏幕 | 使用全局逻辑坐标，支持扩展屏、负坐标和显示器变更找回 |
| 窗口边缘站立 | 普通窗口顶边，排除最小化 / 隐藏 / 完全遮挡区域；跟随支撑窗口 |
| 托盘与本体右键 | 两处菜单均提供动作、手动 / 穿透开关与退出 |
| 手动模式 | 左右移动、上下切换动作、空格跳跃、Esc 返回自动 |
| 透明模式 | 全窗口鼠标穿透；托盘“找回”恢复，系统允许时附快捷键 |
| 图像缩放 | 默认 2 倍，0.75～3 倍可调 |
| 帧率设置 | 15 / 30 / 60 FPS 物理刷新上限，动作按真实时长播放 |
| 下边界距离 | 在系统工作区基础上再调节 0～160 逻辑像素 |
| 描边与阴影 | 本体轻轮廓和落脚面轻影开关 |
| 登录自启 | 当前用户的 Windows Run 项，可选，默认关闭 |
| 多形态切换 | 单角色专属版本，无多套官方形态；以坐卧、招手、思考等动作切换提供互动 |
| 多角色 / 模型搜索 / 模型下载 / 敌方攻击 | 属于 Ark-Pets 的模型库和多角色管理能力；本版为祀专属应用，不实现模型库、其他干员或敌方角色 |
| 启动器公告 / 在线更新 / Mirror 服务 | 本版采用离线便携分发；后续版本替换程序文件夹即可 |

新增：摸头、点心冷却、亲密度、心情、本地手记、专注计时、原创陪伴短句和十六方向视线。

## 模型约束

窗口落脚模拟只包含顶边，不进行其他应用内部控件识别。拖拽可以跨屏；自主散步在当前可用屏幕区域内进行。混合 DPI 与真实多屏仅在代码中处理并做模拟边界检查，本次实机环境只有一台 200% 缩放显示器，详见验证记录。
