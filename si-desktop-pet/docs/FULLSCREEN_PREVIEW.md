# 全屏时减少遮挡（源码预览）

开启“行为与显示 → 全屏应用时自动隐藏，退出全屏后恢复”（默认开启）后，每0.5秒检查前台窗口是否覆盖完整显示器。仅匹配窗口与显示器的物理边界；普通最大化工作区窗口不算全屏。不读取窗口标题、屏幕图像或应用内容。

只隐藏位于同一显示器的桌宠及其气泡，拒绝新的陪伴语音与专注完成通知；手动隐藏状态优先，退出全屏不会将用户手动隐藏的桌宠重新显示。关闭开关会恢复暂时隐藏的桌宠。已开始播放的语音不在本功能中中断，焦点变化至其他普通窗口后会恢复。

验证：真实Qt对象下模拟同屏全屏、退出恢复、另一显示器全屏、手动隐藏优先与开关关闭；物理坐标测试覆盖负坐标屏幕及最大化工作区。Windows原生检测函数在本机实际调用成功（当前没有全屏前台），证据 qa/fullscreen-native-read.json。隔离应用启动通过 qa/fullscreen-app-smoke.json。

原生受控窗口检查发现 Qt 友好名称与 Windows 设备名不同，已改用显示器原点映射；另拒绝保留标题栏的普通窗口。映射依据 [Qt 高 DPI 文档](https://doc.qt.io/qt-6/highdpi.html) 中 Windows 屏幕原点保持物理坐标、尺寸缩放的规则。受控 Qt 窗口的最大化/全屏原生分类已通过，报告 `qa/fullscreen-controlled-native.json`。最初探针会将阶段切换与窗口关闭后的采样覆盖到上一阶段，已改为记录每阶段发布后的首次快照，旧探针结果不用于验收。

测试窗口未取得前台焦点，因此上述检查仅证明原生分类及映射，不证明前台切换到自动隐藏的完整链路。真实游戏/独占全屏/混合DPI物理多屏切换仍未验收。2.0.0a4加入此功能，冻结包检查见该版验证报告；2.0.0a3不包含它。
