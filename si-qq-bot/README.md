# 小祀 QQ 陪伴 0.2.1

本次更新：群回复保留原生@消息段，在第一条正文前增加一个空格；精简重复人设提示，日常口吻演示不写入真实聊天记录，正式任务按所需文体处理。详情见 NATURAL-CHAT-0.2.1.md。

本版接入Qwen3.5 9B与本地能力路由，详见 README-ROUTER.md。当前电脑默认文字和图片共用新模型；旧视觉模型可在窗口勾选对比，避免频繁冷加载。

本版更新群聊附件、长回复分条、祀的对话表达和公开搜索。沿用原管理员绑定与聊天记录。

## 使用

1. 启动本机 Ollama，保持其窗口运行。
2. 在 NapCat 启动小祀专用 QQ，确认显示“QQ 已登录”。
3. 本机使用 `F:\si_accompany\启动小祀QQ.cmd`。入口会复用已绑定专用账号的本机 NapCat 连接，无需反复粘贴令牌。新电脑首次使用或 NapCat 配置位置不同，仍需在窗口填写 OneBot Token、核对专用账号并绑定。

当前本机接口为 `http://127.0.0.1:11434/v1`。模型配置 `si-qwen3.5:9b` 复用已下载的 Qwen3.5 9B Q4_K_M 权重，只调整上下文和生成参数；原始新旧模型均保留。模型文件仍在 `E:\Ollama\models`，未包含在这个程序包中。本地模型无需 API Key。

## 群聊附件

- 图片、表情、文件等非文本消息先静默暂存；普通文字未 @ 时丢弃。
- 在同一个群，发送者随后真正 @小祀，才会取出自己的待处理附件并回复。不会取用其他群或其他人的附件。
- 支持先发表情包/图片/文件，再单独 @，也支持带文字 @。群文件上传通知也会暂存。
- 暂存只在内存中，每群每人最多16条、最多10分钟；全局容量有限，超出会淘汰较早内容。关闭群聊、断开或重启会清空。
- 当前支持图片、QQ 系统表情名称、动图采样帧，以及文本、PDF、Word 文档的有限文本摘录。扫描 PDF、加密文件、视频、语音等未接入解析的内容，会明确说明未能读取，不猜测。
- 单文件最大10MB，单次最多处理8个可解析附件、4个图像帧和4000字符文件摘录；图片最长边1024像素，动画最多采样首/中/尾3帧。没有完整观看动画或完整阅读大文件的承诺。

QQ 附件经本机已认证连接获取，再由本机模型识别；需要下载时使用指定 QQ CDN 的 HTTPS 地址。对于本机 NapCat 已下载的文件，只读已核对的 F:\QQ下载文件\NapCat\temp 缓存目录，拒绝外部路径和链接/联接目录；其他电脑需要配置其正确缓存目录。原始图片、文件内容、下载地址及令牌不写入聊天记录。群聊和私聊仍分别保存；群回复不会带入私聊偏好或私聊记录。私聊附件仅处理已绑定管理员发来的好友消息。

私聊会在内存中保留管理员最近一次附件批次10分钟；随后说“这是什么”“概括文件”等可继续处理。新附件替换旧批次，重启清空，不跨账号或群聊使用。

## 本地角色知识

内置53段带来源资料：5段终末地官网摘要、1段明日方舟社区档案摘要、47段用户角色设计。官网、社区档案、用户设定分别标记，二创不是官方事实；不是全量百科。询问相关角色知识时按中文词项检索，最多3段，不把私聊或管理员真实资料加入知识库。

BGE-M3官方下载被环境的非公网地址检查拒绝，当前没有嵌入模型和向量库，采用本地BM25词项检索。embed_corpus.py保留可选向量建库入口；不会自动下载或使用镜像。未命中时提示模型承认资料不足，但小模型仍可能不严格遵循，需继续验收。

## 分条和表达

短回复保持一条；较长回复按段落、完整句子和列表项分条，普通单条优先约120字，最长220字。代码块采用单独边界。全部分条按顺序等待 QQ 确认，群聊仅首条 @发送者。

全部分条确认后才记为完整回复；中途失败或结果不明不会自动重发。请核对已收到的内容，再使用本机恢复功能。升级前会备份本机记录，旧程序包仍保留；0.2.1 产生超过旧长度限制的记录后，回退旧版应使用升级前备份。

日常以祀的身份自然交流，减少客服式结尾、反复自我介绍和强行追问；对创作数量增加了明确约束。角色与技术事实区分，未执行的操作不声称已完成。对话质量仍受本机小模型能力影响，需要继续根据实际体验校准。

## 搜索和查询

可以说“祀，帮我查一下……”或使用 `/搜索 关键词`。明确的近期天气、新闻、价格等查询也会尝试公开检索。Bing 只接收本条查询词，聊天历史、管理员资料和附件内容不用于生成搜索请求。结果附带来源链接；搜索失败不会伪称已查到。

“本次允许联网搜索”可在窗口关闭，关闭后当前运行期间不会调用搜索。搜索摘要属于外部资料，不能改写角色、管理员身份或操作权限。它是公开网页摘要检索，不保证覆盖所有实时信息，也不等同于读过每篇全文。

## 验证与边界

离线回归、假 OneBot 的附件收取/@关联、跨群跨人隔离、分条确认与中断恢复、配置和后台生命周期均有检查；另有本地实际对话、视觉和公开查询的合成测试。打包与真实 QQ 附件验收结果以 `qa/release-0.2.1-validation.json` 及本次验收记录为准。

本版是 QQ 陪伴更新，桌宠新形象、完整动作、多端实机协同和 QQ 语音回复的整体目标仍在继续开发。
