# 小祀 QQ 0.2.1：本地能力路由

官方 Qwen3.5 9B Q4_K_M 已成功下载到 E:\Ollama\models。小祀使用 si-qwen3.5:9b 配置别名，复用原权重、8K上下文。原新旧模型均保留，不是覆盖或微调。

## 路由行为

- 默认文字、图片共用新模型，减少在两个大模型间切换造成的冷加载。文件正文、QQ系统表情也由文字路线处理。
- “启用本地能力路由”是本次运行开关；本机启动入口会打开。直接启动EXE时默认关闭，使用“模型连接”的单模型设置。两种模式下新模型都关闭显式思考输出。
- 可勾选“图片改用旧视觉模型”作对照；本机从新文字模型切回旧视觉模型约81秒，不建议频繁切换。
- 根据当前实际内容分流，不额外运行分类模型；历史图片和文字里的“换模型”指令不改变连接或权限。
- 每次请求捕获不可变设置，途中修改只影响下一轮。模型缺失时明确失败，不静默重试或转发云服务。
- 仅对本机Ollama生效。其他服务保持原选择；管理员绑定、私聊/群聊隔离、分条确认机制保留。

## 验证

396项程序测试通过；冻结程序与15个自有模块源码一致，全新解压离线启动检查通过。

新模型实际通过身份回应、安静陪伴、知识检索、未知人物生日不编造、三句创作和算术测试。合成图片颜色形状识别通过，随后文字与Word正文请求约2～3秒；再次输入不同图片约4秒，识别通过。全部原始测试输出保留。

首次加载约80～92秒，保持服务运行可避免重复冷加载；重启、显存被占用或切换模型后可能再次等待。
