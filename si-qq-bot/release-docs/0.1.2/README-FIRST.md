# 小祀 QQ 私聊连接器 0.1.2（Windows x64 便携版）

本包只提供本机 QQ 私聊连接窗口，不包含 QQ、NapCat 或模型代理。首次使用前，请阅读同目录的完整说明：[NapCat 使用说明](NapCat-使用说明.md)。

## 启动前

- 从 0.1.1 升级时，先断开并完全退出旧版（包括控制台），确认旧版后台任务已结束，再启动本版。0.1.1 不参与本版的目录锁，不能同时运行。
- 本机需已安装并运行 QQ 和 NapCat；专用 QQ 账号必须由你本人在 NapCat 中扫码登录。
- 请同时运行已部署的模型代理。本包不会启动或检测模型代理，其当前是否可用需以实际检查为准。
- 本包仅使用本机回环连接：`ws://127.0.0.1:3001/`。不要将 NapCat 的 WebSocket 端口暴露到局域网或公网。
- 运行 `SiQQ-0.1.2-Windows-x64.exe`。程序会打开主窗口和一个控制台窗口；使用期间请保持控制台打开，关闭控制台会结束程序。

## 连接和绑定

1. 在 NapCat 中为专用账号启动 OneBot 正向 WebSocket：监听 `127.0.0.1`、端口 `3001`、路径 `/`、角色 `Universal（API + 事件）`、消息格式 `Array`，并启用 Token 鉴权。
2. 在程序窗口中输入本机 NapCat 生成的 OneBot Token，点击“连接”。Token 由你本人在本机输入，不写入本发布包；不要填写 QQ 密码或 NapCat WebUI 密码。
3. 连接后先核对窗口显示的账号号码，必须与专用 QQ 账号一致。不一致时立即断开，不要生成绑定码。
4. 号码正确时点击“生成绑定码”，再用管理员自己的 QQ 私聊该专用账号，发送 `绑定 <绑定码>`。绑定由你本人完成；程序不会自动登录、自动绑定，也不会向群聊发消息。

完整字段、首次登录步骤和排错说明见 [NapCat 使用说明](NapCat-使用说明.md)。

## 运行问题和验证边界

- 遇到运行问题，先断开并关闭程序，再检查本机窗口提示、NapCat 的登录和连接状态、模型代理及 Token。
- 若提示上一条 QQ 回复结果不明，不要自动重发，也不要反复点击。先核对 QQ 客户端和本机提示；确认后由你手动点击“恢复未确认回复”。该操作只清除本机未确认状态，不会重发，也不能证明消息已送达或未送达。
- 已完成的验证：本机 QQ 和 NapCat 组件已安装，专用账号已由用户登录；87 项模拟与离屏测试通过。真实私聊收发及模型回复尚未验证，不能声称端到端成功。模型代理当前是否可用尚待确认。
- 下载 GitHub 或 Node.js 组件时只使用原站；不建议使用镜像、代理下载站或第三方重打包文件。

本包不预置用户 QQ 号码、用户 OneBot Token 或聊天记录。模型代理接口使用程序内置的本机默认鉴权值，用户自己的学校登录凭据不随包提供。QQ 消息会经过腾讯 QQ 平台和本机模型代理处理，并非纯离线。
