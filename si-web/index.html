项目简介

什么是 si_accompany（小祀桌宠 v2.1.2）？

小祀（Si Companion / si_accompany）是一个以《明日方舟：终末地》角色「祀」为形象的非官方开源同人桌面伙伴项目。主打低打扰、离线可用、界面清爽，并提供 Soul Engine V1.2 人格对话、智能语音音效与跨端数据同步。

🎨

3D 精修动作与防穿模升级

v2.1.2 修复蹲坐裙摆穿模并重绘五种高清神态头像，支持自主散步、窗口顶边落脚、拖拽重力与十六方向眼神跟随。

🎧

智能耳机语音 + 拟声词与动作声

接入耳机且未打开 Apex、彩虹六号等本地游戏时默认同时输出语音与文本；支持「哼、咳咳、噗嗤」拟声词与执笔落墨、推茶盏、盖印章等动作音效。

💬

Soul Engine V1.2 数字人格与识图

搭载专属微调人格模型，支持本机 Ollama 离线运行、DeepSeek 官方 API 与学校/第三方兼容接口，多模态窗口可直接拖入图片交流。

🌗

水墨金玉深浅主题自适应

面板、带头像气泡的聊天界面、可折叠连接抽屉与右键菜单自动跟随 Windows 浅色或深色模式切换高对比度配色。

🔒

数据本地保存，隐私安心

亲密度、设置和对话记录全部存放在程序同目录的 data/ 文件夹中；API Key 仅留在运行内存，绝不写入硬盘。

🌐

跨设备与广域网聊天数据同步

支持 sync-v1 事件账本、局域网 TLS 配对、Android 预览包及网页端实时陪伴状态与对话历史双向同步。

    零基础教程

    新手 4 步上手指南

    第一次用绿色压缩包软件？跟着下面 4 个步骤一步一步操作，2 分钟就能让小祀出现在你的桌面上。

    1. 1

      下载压缩包，并「完整解压」到普通文件夹

      点击上方的下载按钮获取 SiDesktopPet-2.1.2-Windows-x64.zip。下载完成后，右键点击该压缩包 → 选择「全部解压缩」（或用 7-Zip / WinRAR 解压），解压到一个好找的位置，例如 D:\SiDesktopPet。

      ⚠️ 新手最容易踩的坑： 请务必完整解压整个压缩包后再运行！不要在压缩包预览窗口里直接双击 EXE，也不要只把 EXE 单独拖到桌面，否则程序会找不到素材和运行库。
    2. 2

      双击启动 Si-DesktopPet.exe

      打开解压后的文件夹，找到带小祀图标的 Si-DesktopPet.exe 并双击运行。首次打开会同时显示「陪伴面板」和桌面上的小祀，离线摸头、投喂和专注计时立即可用！

      💡 如果弹出蓝色的「Windows 已保护你的电脑」提示： 这是 Windows 对未购买商业签名的个人开源软件的常规提示。点击弹窗里的 「更多信息」 → 再点击 「仍要运行」 即可正常启动。
    3. 3

      （可选）配置 AI「自由聊聊」、多模态看图与智能语音

      如果想让小祀接入大模型和你自由聊天，在陪伴面板右侧点击「自由聊聊」或「多模态聊聊」，按你的条件三选一；若本机装有 VoiceStudio，插上耳机且未开游戏时会自动同步发声：

      • 1. 前往 platform.deepseek.com 注册并创建一个 API Key（以 sk- 开头）。
      • 2. 在小祀聊天窗口里，「连接方式」选择 DeepSeek 官方 API，地址会自动填好，默认模型 deepseek-chat。
      • 3. 粘贴你的 API Key 即可开始纯文字聊天（Key 仅留在当前内存，关闭软件不写盘）。
      • 1. 「连接方式」选择 自定义模型接口（学校 API / 第三方）。
      • 2. 填入学校或平台提供的 OpenAI 兼容 Base URL（如 https://api.school.edu.cn/v1）并粘贴 API Key。
      • 3. 点击右侧 「获取模型」 选择可用模型；若所选模型支持视觉，在「多模态聊聊」里拖入图片就能一起聊。
      • 1. 先在电脑上启动 Ollama（默认端口 11434）或 LM Studio（默认端口 1234）。
      • 2. 「连接方式」选择 本机模型（Ollama / 本地端口），默认适配 si-qwen2.5-3b-lang-lora:latest。
      • 3. 点击「获取模型」选择本机已下载模型，完全离线运行不消耗外部流量。
    4. 4

      日常小贴士：找回小祀、退出与备份记录

      • 找不到桌宠 / 开了鼠标穿透？ 按快捷键 Ctrl + Alt + S，或右键电脑右下角任务栏托盘的小祀图标，点击 「找回祀」。
      • 怎么彻底退出？ 关闭陪伴面板后小祀会继续留在桌面；右键小祀或托盘图标选择「退出桌宠」即可关闭。
      • 换电脑 / 升级新版本？ 先完全退出旧版，把文件夹里的 data/ 复制到新版目录，亲密度与聊天记录就会完整保留。

    答疑解惑

    新手常见问题 (FAQ)

    我不懂编程、电脑没装 Python，可以直接用吗？

    完全可以！Windows 便携版已经把所有运行环境都打包好了，下载 ZIP 后完整解压，双击 Si-DesktopPet.exe 就能直接运行，不需要安装 Python 或任何命令行工具。

    打 Apex、彩虹六号等游戏时小祀会突然出声干扰听脚步吗？

    不会！v2.1.2 内置实时音频端点与本地游戏进程检测：仅在接入耳机且未运行 Apex、彩虹六号、CS2、瓦罗兰特、永劫无间等游戏时自动发声；一旦打开游戏或拔下耳机，会立即自动静音并切换为纯文本显示。

    下载打开时 Windows 提示「已保护你的电脑」，是病毒吗？

    不是病毒。由于个人开源项目没有购买昂贵的商业代码签名证书，Windows SmartScreen 会对新打包的 EXE 弹出提醒。点击「更多信息」→「仍要运行」即可，你也可以核对上方提供的 SHA-256 校验值或直接查看 GitHub 开源代码。

    我的 API Key 和聊天记录安全吗？

    所有本地对话记录与设置仅保存在你电脑的 data/ 目录中；API Key 只保留在程序运行内存里，绝不会写入本地文件或上传给第三方。

    开启「鼠标穿透」后点不到小祀了怎么办？

    按下键盘快捷键 Ctrl + Alt + S，或者在电脑右下角任务栏系统托盘找到小祀图标，右键选择「找回祀」即可立刻恢复可点击状态。
